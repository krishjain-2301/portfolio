# Krish Jain — Portfolio

Animated portfolio site for AI Red Teaming & Cybersecurity.

## Tech Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Deploy

Deploy easily on [Vercel](https://vercel.com) — connect your GitHub repo and deploy with one click.
